Sabah Indigenous Heritage

The Beat of the Murut Warriors

Magunatip is a traditional bamboo dance of the Murut people, one of the major indigenous communities in Sabah, Malaysia. Dancers move gracefully with precise footwork, agility, and coordination to avoid being caught by the clashing bamboo poles.

Origins

The Spirit of the Bamboo Clash

Magunatip is a vibrant symbol of Sabah's rich traditions, requiring extreme concentration, balance, and teamwork.

Playful Beginnings

The Paddy Field Tripping Game

The name is derived from the Murut word "atip", meaning "to pinch", referring to the rhythmic opening and closing of two bamboo poles that form the central feature of the dance.

Warrior Heritage

Headhunting & Spirit Healing

Historically, the dance was associated with celebrations, healing rituals, and the welcoming of victorious warriors. The clashing sound of the bamboo was believed to scare away evil spirits causing illness.

Today

The Cultural Pride of Sabah

Today, Magunatip is widely performed during cultural festivals, weddings, official ceremonies, and tourism events, serving as a vibrant symbol of Sabah's rich traditions and the enduring cultural identity of the Murut people.

The Beats

Understanding the Steps

Magunatip relies on the fast-paced, rhythmic clapping of the bamboo poles. Learn the basic sequence of footwork to dance along.

01

Beat 1: The Slide OPEN

The bamboo players slide the poles outwards and tap them flat on the ground. This produces a low, hollow thud sound. During this beat, the poles are open—the dancer steps inside with their left foot.

02

Beat 2: The Strike CLOSED

The players raise the poles and strike them together in mid-air. This makes a loud "clack" sound. The dancer steps inside with their right foot, remaining in the open gap briefly before jumping out.

03

Beat 3: The Leap CLOSED

The poles remain closed as they are struck together again. The dancer must leap quickly outside the poles to the left or right to avoid getting their feet caught by the fast-moving wood.

Culture

Attire & Traditional Instrumentation

Every aspect of Magunatip, from the colorful beadwork to the deep resonating gongs, is rich with Murut culture and heritage.

Traditional Attire & Murut Regalia

Dancers wear elaborate traditional Murut attire. Women wear the Pinongkolo or Limpur, a beautifully hand-beaded black dress decorated with geometric beadwork patterns called Rarik and silver coin belts called Pipirot. They wear the Sugu Tinggi headpiece adorned with tail feathers of the Great Argus Pheasant (Burung Kuang). Men wear the Babaru Puot (a black bark vest with red details), a loincloth, and the Pinongkol feathered headgear. Warriors dance completely barefoot to navigate the rapid poles.

The Bamboo Poles (Buluh Tering)

The dance utilizes thick green bamboo poles (usually 9 to 12 feet long) of the Buluh Tering species, which are cured over hearth smoke. Placed horizontally over floor blocks, the poles are rhythmically clashed together by players to drive away malevolent forest spirits (Rogh), a task historically led by high priestesses (Babalian).

🎋

Bamboo Clashing

The primary source of sound in Magunatip. The rhythmic clack of the bamboo poles hitting each other and the floor blocks dictates the tempo of the dancers.

🎯

Sansaring (Gongs)

Traditional brass gongs of different pitches that provide melodic and rhythmic backing, guiding the dancers through speed transitions.

🥁

Jarang (Drums)

Traditional single-headed skin drums that provide deep bass beats, matching the opening taps of the bamboo cycles.

📄 ESP32 Arduino Firmware Code (esp32_led_control.ino)

Flash this C++ code to your ESP32 board using the Arduino IDE to control connected LED lightbulbs over Wi-Fi or USB.


/*
 * ESP32-Only LED & Adafruit NeoPixel Controller with Ultrasonic Sensor
 * Designed for Future Innovator Showcase / NRC2026
 * 
 * Hardware Connections:
 *   - LED Pin: GPIO 23 (Connected to MOSFET/Dimmer)
 *   - Onboard Status LED: GPIO 2
 *   - NeoPixel Data Pin: GPIO 4
 *   - Ultrasonic Sensor (HC-SR04):
 *       * Trig: GPIO 12
 *       * Echo: GPIO 13
 *   - I2C Bus (Expansion Board):
 *       * SDA: GPIO 21
 *       * SCL: GPIO 22
 * 
 * Modes:
 *   - FAST: Turn LED on, NeoPixels controlled by Ultrasonic Sensor.
 *   - SLOW (Default): Turn LED off, NeoPixels controlled by Ultrasonic Sensor.
 *   - OPEN: Static Green NeoPixels (Game Mode).
 *   - CLOSED: Static Off state (Game Mode).
 */

#include <WiFi.h>
#include <WebServer.h>
#include <Wire.h>
#include <Adafruit_NeoPixel.h>

// --- HARDWARE CONFIGURATION ---
const int LED_PIN = 23;          // GPIO 23
const int STATUS_LED = 2;       // Onboard LED (GPIO 32)
const int NEOPIXEL_PIN = 4;     // GPIO 4 (First NeoPixel strip)
const int NEOPIXEL_PIN_2 = 18;   // GPIO 18 (Second NeoPixel strip)
const int TRIG_PIN = 14;        // GPIO 14 (Trig)
const int ECHO_PIN = 27;        // GPIO 27 (Echo)
const int I2C_SDA = 21;         // GPIO 21 (SDA)
const int I2C_SCL = 22;         // GPIO 22 (SCL)

#define STATUS_ON  HIGH
#define STATUS_OFF LOW

const int NUM_PIXELS = 8;        // Adjust number of NeoPixels as needed
const int NUM_PIXELS_2 = 8;      // Adjust number of NeoPixels for strip 2 as needed
const int DISTANCE_THRESHOLD = 20; // Trigger distance in cm
const int NEOPIXEL_BRIGHTNESS = 50; // Set NeoPixel brightness (0 to 255). 50 is about 20% brightness (recommended).

// --- INITIALIZE NEOPIXELS ---
Adafruit_NeoPixel strip(NUM_PIXELS, NEOPIXEL_PIN, NEO_GRB + NEO_KHZ800);
Adafruit_NeoPixel strip2(NUM_PIXELS_2, NEOPIXEL_PIN_2, NEO_GRB + NEO_KHZ800);

// Helper function to set the color of both NeoPixel strips
void setStripsColor(uint8_t r, uint8_t g, uint8_t b) {
  uint32_t color1 = strip.Color(r, g, b);
  for (int i = 0; i < NUM_PIXELS; i++) {
    strip.setPixelColor(i, color1);
  }
  strip.show();
  
  uint32_t color2 = strip2.Color(r, g, b);
  for (int i = 0; i < NUM_PIXELS_2; i++) {
    strip2.setPixelColor(i, color2);
  }
  strip2.show();
}

// --- WI-FI CONFIGURATION ---
const bool CONNECT_TO_ROUTER = false; //if got wifi or hotspot change to true
const char* ssid_AP = "ESP-LED-Control";
const char* password_AP = "12345678";
const char* ssid_STA = "HSBP ROBOTICS";
const char* password_STA = "robot123";

// --- WEB SERVER & STATE ---
WebServer server(80);
String currentMode = "SLOW"; // Default mode

// --- BLINKING ANIMATION STATE (FAST Mode) ---
unsigned long lastBlinkTime = 0;
const unsigned long blinkInterval = 300; 
bool blinkState = false;
int colorIndex = 0;

const uint32_t blinkColors[] = {
  0xFF0000, 0x00FF00, 0x0000FF, 0xFFFF00, 0xFF00FF, 0x00FFFF, 0xFF5500, 0xFF007F, 0xFFFFFF
};
const int numColors = sizeof(blinkColors) / sizeof(blinkColors[0]);

// Helper to set CORS headers so Web fetch() requests succeed
void setCorsHeaders() {
  server.sendHeader("Access-Control-Allow-Origin", "*");
  server.sendHeader("Access-Control-Allow-Methods", "GET, POST, OPTIONS");
  server.sendHeader("Access-Control-Allow-Headers", "Content-Type");
}

// Helper for PWM output (8-bit ESP32 analogWrite)
void setLedPWM(int pin, int value) {
  analogWrite(pin, value / 4); // Map 0-1023 (input range) to 0-255 (ESP32 range)
}

// Helper function to read distance from Ultrasonic Sensor
long readUltrasonicDistance() {
  int validReadings = 0;
  long totalDuration = 0;
  
  for (int i = 0; i < 5; i++) { // Take 5 samples
    digitalWrite(TRIG_PIN, LOW);
    delayMicroseconds(2);
    digitalWrite(TRIG_PIN, HIGH);
    delayMicroseconds(10);
    digitalWrite(TRIG_PIN, LOW);
    
    long duration = pulseIn(ECHO_PIN, HIGH, 25000); // 25ms timeout
    if (duration > 0 && duration < 30000) { // Check if reading is valid
      totalDuration += duration;
      validReadings++;
    }
    delay(10); // Small delay between readings
  }
  
  if (validReadings == 0) {
    return -1; // All samples failed
  }
  
  long avgDuration = totalDuration / validReadings;
  return avgDuration / 29.1 / 2; // Distance in cm
}


void handleLedRequest() {
  setCorsHeaders();
  
  Serial.println("\n--- New Web Request Received ---");
  Serial.print("Client IP: ");
  Serial.println(server.client().remoteIP());
  
  if (server.hasArg("mode")) {
    currentMode = server.arg("mode");
    currentMode.toUpperCase();
    Serial.print("-> Mode updated to: ");
    Serial.println(currentMode);
  }

  // Send JSON response to browser
  String jsonResponse = "{\"success\":true,\"mode\":\"" + currentMode + "\"}";
  server.send(200, "application/json", jsonResponse);
  
  Serial.println("-> Reply sent to client successfully.");
}

void setup() {
  Serial.begin(115200);
  delay(500);
  
  Serial.println("\n\n==========================================");
  Serial.println("[STEP 1] ESP32 NeoPixel Controller Booting...");
  Serial.println("==========================================");
  
  pinMode(LED_PIN, OUTPUT);
  pinMode(STATUS_LED, OUTPUT);
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  
  digitalWrite(STATUS_LED, STATUS_ON); // Turn status LED on during setup
  
  // Initialize I2C Bus on GPIO 21 and 22
  Wire.begin(I2C_SDA, I2C_SCL);
  Serial.println("[STEP 2a] I2C Wire Bus Configured: SDA=21, SCL=22");
  
  // Initialize NeoPixel strips
  strip.begin();
  strip.setBrightness(NEOPIXEL_BRIGHTNESS);
  strip.show(); // Turn off all pixels
  strip2.begin();
  strip2.setBrightness(NEOPIXEL_BRIGHTNESS);
  strip2.show(); // Turn off all pixels
  Serial.println("[STEP 2b] Hardware Pins & NeoPixels Configured Successfully.");

  // Setup Wi-Fi
  Serial.println("[STEP 3] Initializing Wi-Fi Network...");
  if (CONNECT_TO_ROUTER) {
    WiFi.mode(WIFI_STA);
    WiFi.disconnect();
    delay(100);
    WiFi.begin(ssid_STA, password_STA);
    Serial.print("         -> Connecting to router: ");
    Serial.println(ssid_STA);
    
    int retries = 0;
    while (WiFi.status() != WL_CONNECTED && retries < 20) {
      delay(500);
      Serial.print(".");
      retries++;
    }
    
    if (WiFi.status() == WL_CONNECTED) {
      Serial.println("\n         -> [SUCCESS] Connected to Wi-Fi!");
      Serial.print("         -> Local IP Address: ");
      Serial.println(WiFi.localIP());
    } else {
      Serial.print("\n         -> [FAILED] Connection failed. Status code: ");
      Serial.println(WiFi.status());
      Serial.println("         -> Falling back to Access Point mode...");
      WiFi.mode(WIFI_AP);
      WiFi.softAP(ssid_AP, password_AP);
      Serial.print("         -> [AP READY] Network Name: ");
      Serial.println(ssid_AP);
      Serial.print("         -> [AP READY] IP Address: ");
      Serial.println(WiFi.softAPIP());
    }
  } else {
    WiFi.mode(WIFI_AP);
    WiFi.softAP(ssid_AP, password_AP);
    Serial.println("         -> [SUCCESS] Started Access Point!");
    Serial.print("         -> Network Name (SSID): ");
    Serial.println(ssid_AP);
    Serial.print("         -> IP Address: ");
    Serial.println(WiFi.softAPIP());
  }

  // --- HTTP ROUTE HANDLERS ---
  Serial.println("[STEP 4] Registering Web Server Endpoints...");
  
  server.on("/led", HTTP_OPTIONS, []() {
    setCorsHeaders();
    server.send(204);
  });

  server.on("/led", HTTP_GET, handleLedRequest);
  server.on("/led", HTTP_POST, handleLedRequest);
  
  server.on("/", HTTP_GET, []() {
    setCorsHeaders();
    Serial.print("[HTTP] Received Ping on Root (/) from: ");
    Serial.println(server.client().remoteIP());
    String html = "{\"status\":\"online\",\"mode\":\"" + currentMode + "\"}";
    server.send(200, "application/json", html);
  });

  server.begin();
  Serial.println("[STEP 5] Web Server Started on Port 80.");
  
  Serial.println("==========================================");
  Serial.println("           SYSTEM FULLY READY             ");
  Serial.println("==========================================\n");
  digitalWrite(STATUS_LED, STATUS_OFF); // Turn status LED off (ready)
}

void loop() {
  // 1. Handle incoming HTTP requests
  server.handleClient();

  // 2. Handle incoming Serial Commands from USB Web Serial
  if (Serial.available() > 0) {
    String serialInput = Serial.readStringUntil('\n');
    serialInput.trim();
    serialInput.toUpperCase();
    
    if (serialInput.indexOf("OPEN") >= 0) {
      currentMode = "OPEN";
      Serial.println("[SERIAL CMD] Switched to OPEN (Light Up)");
    } else if (serialInput.indexOf("CLOSED") >= 0) {
      currentMode = "CLOSED";
      Serial.println("[SERIAL CMD] Switched to CLOSED (Turn Off)");
    } else if (serialInput.indexOf("FAST") >= 0) {
      currentMode = "FAST";
      Serial.println("[SERIAL CMD] Switched to FAST mode (LED 255, Sensor Active)");
    } else if (serialInput.indexOf("MEDIUM") >= 0) {
      currentMode = "MEDIUM";
      Serial.println("[SERIAL CMD] Switched to MEDIUM mode (LED 48, Sensor Active)");
    } else if (serialInput.indexOf("SLOW") >= 0) {
      currentMode = "SLOW";
      Serial.println("[SERIAL CMD] Switched to SLOW mode (LED OFF, Sensor Active)");
    }
  }

  // 3. Read Ultrasonic distance (always runs for sensor-driven NeoPixels)
  long distance = readUltrasonicDistance();
  
  static unsigned long lastSensorDebug = 0;
  if (millis() - lastSensorDebug >= 60000) { // Log every 1 minute
    lastSensorDebug = millis();
    Serial.print("[SENSOR] Distance: ");
    if (distance == -1) {
      Serial.println("Out of range / error");
    } else {
      Serial.print(distance);
      Serial.println(" cm");
    }
  }

  // 4. LED & NeoPixel Control based on currentMode
  if (currentMode == "OPEN") {
    // Game Mode - Open
    setStripsColor(0, 255, 0); // Green
    setLedPWM(LED_PIN, 1023);
    digitalWrite(STATUS_LED, STATUS_ON);
  } 
  else if (currentMode == "CLOSED") {
    // Game Mode - Closed
    setStripsColor(0, 0, 0); // Off
    setLedPWM(LED_PIN, 0);
    digitalWrite(STATUS_LED, STATUS_OFF);
  }
  else if (currentMode == "FAST") {
    // FAST Mode: LED is constantly ON at 255 brightness, NeoPixels respond to Ultrasonic sensor
    setLedPWM(LED_PIN, 255 * 4); // 255 * 4 = 100% (analogWrite=255)
    digitalWrite(STATUS_LED, STATUS_ON);
    
    if (distance > 0 && distance < DISTANCE_THRESHOLD) {
      setStripsColor(0, 255, 255); // Cyan
    } else {
      setStripsColor(0, 0, 0); // Off
    }
  }
  else if (currentMode == "MEDIUM") {
    // MEDIUM Mode: LED is constantly ON at 48 brightness, NeoPixels respond to Ultrasonic sensor
    setLedPWM(LED_PIN, 48 * 4); // 48 * 4 = 192 (analogWrite=48)
    digitalWrite(STATUS_LED, STATUS_ON);
    
    if (distance > 0 && distance < DISTANCE_THRESHOLD) {
      setStripsColor(0, 255, 255); // Cyan
    } else {
      setStripsColor(0, 0, 0); // Off
    }
  }
  else { // SLOW Mode (Default): LED is OFF, NeoPixels respond to Ultrasonic sensor
    setLedPWM(LED_PIN, 0);
    digitalWrite(STATUS_LED, STATUS_OFF);
    
    if (distance > 0 && distance < DISTANCE_THRESHOLD) {
      setStripsColor(0, 255, 255); // Cyan
    } else {
      setStripsColor(0, 0, 0); // Off
    }
  }
}
